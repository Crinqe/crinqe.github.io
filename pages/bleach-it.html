Bleach It!

About the Game

A 2D cleaning simulator game where the player must clean up the crime scene before the police arrive!

What We Created

  • Designed a 2D cleaning simulator game inspired by games such as PowerWash Simulator and Crime Scene Cleaner
  • Collaboratively coded the game from scratch; All mechanics were created by the team
  • Created all major art assets, excluding game environment tileset and fonts

Individual Contributions

  • Role: UI Art / UX Design
  • Art for all menu screens
  • Art for in-game UI, such as sprite sheets for timer and progress bars
  • Button Art
  • Implementing art that I created
  • Designing, creating, and implementing the tutorial
  • Implementing changes to UI according to user feedback gathered in our play testing session
