Starving Snake

About the Project

A 2D game made for the web where the player is a snake and they must eat as much as they can!

What I Created

  • Role: Front-End Web Developer, Game Developer
  • Implemented game logic and mechanics with JavaScript
  • Designed the UI to match a classic arcade game using HTML and CSS
  • Used the PixiJS API for snake and fruit sprites
  • Created the background grid texture

Tools
