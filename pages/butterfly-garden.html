Butterfly Garden

About the Simulation

Butterflies and birds fly around the butterfly garden in this 2D Simulation!

What I Created

  • Role: Programmer / 2D Artist
  • Implemented program mechanics using C# and Unity
  • Designed and Created all 2D art assets
  • Developed the program to simulate a real-world environment
  • Birds wander around the scene
  • Blue butterflies wander with their flock that follow a leader (indicated by the dark blue butterfly)
  • Orange butterflies follow a predetermined path between each flowerbed

Tools
